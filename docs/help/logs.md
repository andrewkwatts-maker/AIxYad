# Logs

The Logs screen shows all agent actions in real time.

**Columns:**
- **Timestamp**: When the action occurred
- **Agent**: Which AI agent performed the action
- **Action**: What was done (read_file, write_file, run_tests, etc.)
- **Summary**: Brief description
- **Status**: done / in_progress / failed / blocked

**Filters:**
- Use the filter chips to show All, Errors only, or Done entries
- Toggle between Compact and Full JSON view
- Pause/Resume the live polling with the PAUSE button

**Pagination:**
- The log loads 50 entries at a time
- Click "Load More" to fetch older entries
