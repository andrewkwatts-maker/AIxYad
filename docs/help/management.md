# Management

The Management section lets you manage Projects, Sprints, and Tasks.

**Projects tab:**
- Register project directories for AI agent work
- Each project gets its own SQLite database at `.aixyad/project.db`

**Sprints tab:**
- Create sprints with a goal and point capacity
- Assign backlog tasks to the sprint
- Start/stop sprints

**Tasks tab:**
- View and filter tasks by status and complexity
- Create tasks with Fibonacci complexity estimates (1-89)
- Tasks move through: backlog → sprint_planned → in_progress → done
