# Settings

Configure Automatica's behavior and connections.

**Connection tab:**
- Switch between Server mode (local DB) and Client mode (remote API)
- Set the API server URL and authentication key

**Providers tab:**
- Add AI providers: Ollama (local), Claude API, OpenAI, Gemini
- Configure model names, API keys, and token limits

**VCS tab:**
- Configure Git settings for auto-commit after task completion
- Set commit message templates

**Behavior tab:**
- Log retention period (default: 30 days)
- Sprint concurrency settings

**Security tab:**
- API key management
- CORS and rate limit configuration

**General tab:**
- Theme: Dark / Light
- Font size: Small / Medium / Large
